# Happo-sai Docs

Guides for the status app used at Happo-sai 2026: stalls report how their sales and queues are going, the committee manages what is published, and a display in the school building shows it live.

The guides are written in Japanese for now.

- [ステータスを送信する（団体向け） — for stalls](/ja/status-org)
- [ステータスを管理する（管理者向け） — for the committee](/ja/status-admin)
- [サイネージを表示する（端末担当向け） — for the signage display](/ja/status-signage)

Setup and deployment are covered in the [repository README](https://github.com/sakana-digital/lpf-2026#readme).
