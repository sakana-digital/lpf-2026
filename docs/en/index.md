# Happo-sai Docs

Guides for the status app used at Happo-sai — LiSA Papillon Festival 2026. Stalls report how their sales and queues are going, admins manage what is published, and displays around school show it live.

::: tip The app is in Japanese
There is no English UI. These guides quote the Japanese labels exactly as they appear on screen, with a translation next to them.
:::

| Who you are | Guide                                  |
| ----------- | -------------------------------------- |
| Stalls      | [Send your status](/en/status-org)     |
| Admins      | [Configure the app](/en/status-admin)  |
| Committee   | [Show the signage](/en/status-signage) |

## Terms

- **Status** — a stall's 販売状況 (sales) and 混雑状況 (queue). Shown on the [Explore](https://happo-sai.pages.dev/explore/events/) page of the public site and on the signage on each floor.
- **Access URL** — the URL handed to each stall, unique to them. A device that opens it stays signed in.

Setup and deployment are covered in the [repository README](https://github.com/sakana-digital/lpf-2026#readme).
