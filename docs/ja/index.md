# 八宝祭 ステータスアプリの使いかた

## このサイトについて

八宝祭 - LiSA Papillon Festival 2026のステータスアプリの各団体向けドキュメントです。

| 読む人         | ドキュメント                               |
| -------------- | ------------------------------------------ |
| 模擬店の各団体 | [ステータスを送信する](/ja/status-org)     |
| 管理者         | [設定する](/ja/status-admin)               |
| 実行委員       | [サイネージを表示する](/ja/status-signage) |

## 用語

- **ステータス** … 各団体の「販売状況」と「混雑状況」。公開サイトの[Explore](https://happo-sai.pages.dev/explore/events/)ページと校舎各階のサイネージに表示されます。
- **アクセス用URL** … 各団体に配られる、それぞれ専用のURLです。そのリンクを開いた端末はログインしたままになります。
