# ステータスを送信する（模擬店の各団体）

模擬店の「販売状況」「混雑状況」を送ると、公開サイトの[Explore](https://happo-sai.pages.dev/explore/events/)ページと校内のサイネージに表示されます。スマートフォンのブラウザなどで使います。

## 1. アクセス用URLを開く

配られるURL (`https://…/?t=…`) を開きます。何人でもログインできます。

- 最初に開いた時点でその端末にログイン情報が保存されます。
- 保存先はブラウザなので、次の場合はやり直しになります。もう一度、配布されたURLを開いてください。
  - シークレット（プライベート）モードで開いた。
  - ブラウザの履歴・サイトデータを削除した。
  - 別の端末・別のブラウザで開いた。
- URLは団体ごとに違います。**他の人に見せたり共有したりしないでください**。他団体のステータスは変更すべきではありません。

画面の右上に自分の団体名が出ていれば準備完了です。

## 2. ステータスを選んで送信する

**販売状況**（どれか1つ）

| 表示       | 意味                             |
| ---------- | -------------------------------- |
| 販売中     | 通常どおり販売している           |
| 一部完売   | 一部売り切れた商品がある         |
| 残りわずか | もうすぐ完売しそう               |
| 販売休止中 | 一時的に販売を止めている         |
| 全て完売   | すべて売り切れ、この後の販売なし |

**混雑状況**（どれか1つ）

| 表示       | 目安                                         |
| ---------- | -------------------------------------------- |
| 空いている | 並ばずに買える                               |
| やや混雑   | 少し列ができている                           |
| 混雑       | 列ができ、注文から提供までにより時間がかかる |

- 初回は両方選ぶことで`更新する`が押せます。「更新しました。」と表示されれば成功です。
- 状況が変わったら送信し直してください。
- 「販売休止中」「全て完売」を選ぶと、混雑状況は選べなくなります。
- 「全て完売」選択時は確認されます。**戻すことはできますが、**慎重に選んでください。
- 画面上部に「最終更新13:20（5分前）」のように、最後に送った時刻が出ます。
- 最大1分で各サイトに反映されます。

## 困ったとき

| 画面の表示                        | 対応                                       |
| --------------------------------- | ------------------------------------------ |
| アクセス用URLが正しくありません。 | 配布されたURL（`?t=…`付き）をもう一度開く  |
| トークンが無効です。              | URLが古い可能性があります。                |
| 読み込み / 送信 に失敗しました。  | 電波を確認してページを再読み込み           |
| 文化祭時間外です。                | 文化祭時間中またはテスト中に送信できます。 |

URLを紛失した・送信できないままの場合は、担当の先生とGoogle Classroomを通じて実行委員に連絡してください。
