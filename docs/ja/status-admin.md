# 管理者: 設定する

管理者用のURLを開くと管理画面になり、ヘッダー右側のタブで「ステータス」と「設定」を切り替えます。

| メニュー   | できること                                                          |
| ---------- | ------------------------------------------------------------------- |
| ステータス | 団体を選んで代理更新・更新履歴を見る                                |
| 設定       | サイネージの表示内容・動画・閲覧URL、受付時間、テスト受付を設定する |

- 「ステータス」タブは左がステータス送信、右が更新履歴です。画面が狭いと縦一列になります。
- 「設定」タブは上が「サイネージ」、下が「ステータス」（受付時間とテスト受付）です。
- 団体はステータス送信の上にあるセレクトで選びます。出てくるのは食品販売・調理の団体だけです。
- 表示中のタブと団体は端末に保存され、次に開いたときも同じ状態から始まります。
- 画面の配色は端末の設定（ライト / ダーク）に追従します。団体向けの送信画面も同じで、サイネージだけが常にダークです。
- 管理者用URLも最初に開いた時点で端末に保存され、URLから`?t=…`が消えます。ブックマークなどして使ってください。
- 各ウィンドウの変更は、**それぞれの保存ボタンを押すまで反映されません**（ステータスは`更新する`）。
- 管理者URLを紛失した場合は再発行が必要です（開発担当へ。手順は[リポジトリのREADME](https://github.com/sakana-digital/lpf-2026/blob/main/apps/status/README.md#トークン運用)）。

## ステータス

セレクトで選んだ団体の販売状況・混雑状況を送信します。選択肢の意味は[団体向けドキュメント](/ja/status-org#_2-ステータスを選んで送信する)と同じです。

- 管理者は**受付時間の制限を受けません**。時間外でも代理更新できます。
- 「全て完売」は`更新する`を押したときに確認されます。

## 更新履歴

選んだ団体の販売状況と混雑状況の推移が、時刻を横軸にした2本の折れ線で出ます（新しい順に最大200件）。

- 上が販売状況、下が混雑状況で、線の色が違います。送信のたびの点を直線でつなぎます。販売休止中・全て完売の間は混雑状況の線が途切れます。
- ドラッグで期間を移動、ホイールで拡大・縮小、ダブルクリックか`全期間`で全体に戻ります。`Day 1`・`Day 2`はその日の開場時間（10:00〜15:30）です。
- 線の上にポインタを置くと、その時点の値と送信者（団体 / 管理者）が出ます。その下の一覧でも確認できます。
- 記録が始まるのは履歴機能を入れたあとの更新からです。それ以前の値は残っていません。
- 履歴は消えません。公開サイトやサイネージには出ず、管理者だけが見られます。

## 受け付ける団体

設定項目ではなく、決め打ちです。

- ステータスを送れるのは**食品販売・調理の団体**だけです。他の団体のURLを開いても「受付対象外です。」と出て送信できず、公開サイトとサイネージにも出ません。団体の区分は[shared/organizations.ts](https://github.com/sakana-digital/lpf-2026/blob/main/shared/organizations.ts)の`category`で決まります。
- サイネージには食品販売・調理の団体が団体の並び順で出ます。13団体以上なら10秒ごとにページが切り替わります。

## 受付時間

団体がステータスを送信できる時間帯で、「設定」タブの「ステータス」にあります。

- 初期値は[shared/timetable.ts](https://github.com/sakana-digital/lpf-2026/blob/main/shared/timetable.ts)の開催日と開場時間（両日とも10:00〜15:30）です。
- Day 1 / Day 2それぞれの開始・終了を変えて`時間を保存`すると、その時間だけ受け付けます。`開場時間に戻す`で初期値に戻せます。
- 管理者の代理更新は時間に関係なくできます。

## テスト受付

準備日に団体へ送信を試してもらうための機能です。「設定」タブの「ステータス」にある`テスト受付`を押すと説明が出て、`開始する`で始まります。

- テスト中は、受付時間外でも団体が送信できます。サイネージにもテストの値が出ます。公開サイトは開催日以外はステータスを取得しないので、準備日のテストでは表示されません。
- テスト中の送信は本番とは別の場所に記録します。テスト中は本番のステータスと履歴が見えず、各団体は未送信の状態から始まります。
- 団体の画面には「テスト受付中です。送信内容はテスト終了時に削除します。」と出ます。
- テスト中は同じボタンが`テスト受付中`になります。押して`終了して削除`を選ぶと、テスト分のステータスと更新履歴だけが消えます。本番のデータには一切触れないので、本番中に誤って開始・終了しても失われるものはありません。
- 当日の開始前に必ず終了しておきます。テスト中は本番の値が表示されません。

受付時間外は次のようになります。

- 団体からの送信は「文化祭時間外です。」となり、受け付けません。
- 公開サイトからステータスの表示が消えます。
- サイネージには最後に送られた値がそのまま出ます。

## サイネージ

「設定」タブの上段です。設定は`サイネージ設定を保存`を押すと、表示中の端末に約1分で反映されます。

### フッター情報

画面下部の帯に出る文章です。優先順位は**速報 → タイムテーブル → 固定案内**です。

- **固定案内**（120文字まで）… 予定が近くにない時間帯に出る文章。例:落とし物は本部まで
- **速報**（200文字まで）… `速報を配信する`をオンにして文章を入れると、常にこれだけが出ます。緊急の連絡用なので、終わったらオフに戻してください
- タイムテーブルを自動で表示します。開始10分前から終了までの企画を`まもなく/開催中/次は`の形で流します

### 動画

- MP4のみ、1ファイル1 GiBまで。アップロード中は進捗が出て、`中止`で止められます。
- ラジオボタンで再生する動画を選びます。`動画を表示しない`にすると`映像準備中`の画面になります
- `再生を始める時刻`を入れると、その時刻まで各端末は`映像準備中`で待ち、時刻になったら再生を始めて以降はループします。`すぐ再生`を押して保存すれば解除（未設定なら保存後すぐ再生）
  - 判定は端末の時計です。最大10秒ほど遅れて始まります
- 再生は自動・ループで、音声は最初オフです。鳴らすなら端末側で1回タップします（[サイネージを表示する](/ja/status-signage)）
- 表示中の動画は削除できません。別の動画に切り替えてから削除してください。

### 閲覧URL

サイネージ端末に渡すURLを発行します。

- 発行したURLはこの画面（この端末のブラウザ）にだけ残ります。クリックでコピーできます。
- **再発行すると以前のURLと、それで表示中の端末はすべて無効になります**。表示が止まるので、掲示中は避けてください。
- 端末側の使い方は[サイネージを表示する](/ja/status-signage)を参照。

## 当日の流れ（めやす）

1. 前日までに「設定」でサイネージと受付時間を確認し、端末に閲覧URLを仕込んでおく。準備日にテスト受付をした場合は終了しておく。
2. 当日は団体からの送信に任せ、送られていない団体があれば「ステータス」で代理更新する。
3. 連絡事項があれば「設定」の速報をオンにし、終わったらオフに戻す。
