# 設定する（管理者）

管理者用のURLを開くと、団体と同じアプリが管理者モードになり、上部に4つのタブが出ます。

| タブ       | できること                                        |
| ---------- | ------------------------------------------------- |
| ステータス | 任意の団体のステータスを代理で更新する            |
| 受付時間   | 団体が送信できる時間帯をDay 1 / Day 2ごとに決める |
| 表示団体   | 公開サイトにステータスを出す団体を選ぶ            |
| サイネージ | サイネージの表示内容・動画・閲覧URLを設定する     |

- 管理者用URLも最初に開いた時点で端末に保存され、URLから`?t=…`が消えます。ブックマークなどして使ってください。
- 各タブの変更は、**それぞれの保存ボタンを押すまで反映されません**（ステータスタブは`更新する`）。
- 管理者URLを紛失した場合は再発行が必要です（開発担当へ。手順は[リポジトリのREADME](https://github.com/sakana-digital/lpf-2026#トークン運用)）。

## ステータス

団体を選んで、その団体の販売状況・混雑状況を送信します。選択肢の意味は[団体向けドキュメント](/ja/status-org#_2-ステータスを選んで送信する)と同じです。

- 管理者は**受付時間の制限を受けません**。時間外でも代理更新できます。
- 画面が広いときは左の一覧から、狭いときは上のセレクトから団体を選びます。

## 受付時間

団体がステータスを送信できる時間帯です。

- Day 1 / Day 2それぞれに開始・終了を設定します。片方だけの設定でも構いません。
- 設定していない日は制限されません。**両日とも未設定なら、いつでも送信できます**。
- `クリア`で入力を空にしてから`時間を保存`すると、制限を解除できます。

受付時間外は次のようになります。

- 団体からの送信は「文化祭時間外です。」となり、受け付けません。
- 公開サイトからステータスの表示が消えます。
- サイネージには最後に送られた値がそのまま出ます。

## 表示団体

チェックを外した団体は、公開サイトにステータスが出なくなります（`n / 31団体`の表示で確認できます）。

- 反映まで最大1分かかります。
- ここでの設定は**公開サイトだけ**に効きます。サイネージに出す団体はサイネージタブで別に選びます。
- ステータスを出さない団体（ステージ企画のみの団体など）を外しておく使い方を想定しています。

## サイネージ

右側のプレビューで、実際の画面を確認しながら設定できます。設定は`サイネージ設定を保存`を押すと、表示中の端末に約1分で反映されます。

### 表示する団体

- ボタンで表示・非表示を切り替え、下のリストの`↑` `↓`で並び順を決めます
- 最低1団体は必要です
- 12団体を超えると自動でページ分割され、10秒ごとに切り替わります

### フッター情報

画面下部の帯に出る文章です。優先順位は**速報 → タイムテーブル → 固定案内**です。

- **固定案内**（120文字まで）… 予定が近くにない時間帯に出る文章。例:落とし物は本部まで
- **速報**（200文字まで）… `速報を配信する`をオンにして文章を入れると、常にこれだけが出ます。緊急の連絡用なので、終わったらオフに戻してください
- タイムテーブルを自動で表示します。開始10分前から終了までの企画を`まもなく/開催中/次は`の形で流します

### 動画

- MP4のみ、1ファイル1 GiBまで。アップロード中は進捗が出て、`中止`で止められます。
- ラジオボタンで再生する動画を選びます。`動画を表示しない`にすると`映像準備中`の画面になります
- `再生を始める時刻`を入れると、その時刻まで各端末は`映像準備中`で待ち、時刻になったら再生を始めて以降はループします。`すぐ再生`を押して保存すれば解除（未設定なら保存後すぐ再生）
  - 判定は端末の時計です。最大10秒ほど遅れて始まります
  - 右のプレビューは時刻に関係なく再生します
- 再生は自動・ループで、音声は最初オフです。鳴らすなら端末側で1回タップします（[サイネージを表示する](/ja/status-signage)）
- 表示中の動画は削除できません。別の動画に切り替えてから削除してください。

### 閲覧URL

サイネージ端末に渡すURLを発行します。

- 発行したURLはこの画面（この端末のブラウザ）にだけ残ります。クリックでコピーできます。
- **再発行すると以前のURLと、それで表示中の端末はすべて無効になります**。表示が止まるので、掲示中は避けてください。
- 端末側の使い方は[サイネージを表示する](/ja/status-signage)を参照。

## 当日の流れ（めやす）

1. 前日までに「表示団体」「サイネージ」を設定し、端末に閲覧URLを仕込んでおく。
2. 開始前に「受付時間」をDay 1 / Day 2分設定する。
3. 当日は団体からの送信に任せ、送られていない団体があれば「ステータス」タブで代理更新する。
4. 連絡事項があれば「サイネージ」タブの速報をオンにし、終わったらオフに戻す。
