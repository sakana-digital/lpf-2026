# サイネージを表示する（実行委員全体）

校内に置くディスプレイに、各団体の販売・混雑状況と動画を映すための画面です。ブラウザでURLを開いて表示します。

## 準備

1. 管理者に**閲覧URL**を発行してもらう（管理画面の「サイネージ」タブ）。
2. 表示端末のブラウザでそのURLを開く
   - 開いた時点で端末にログイン情報が保存されます。
   - 保存は約30日間有効なので、前日までに仕込んでおけます
   - ゲストモードで開くとうまく表示できません。
   - シークレットモードで開くと保存されません。ブラウザのデータを消した場合もやり直しです
3. ブラウザを全画面表示にする（Google Chromebookはキーボードの最上段にボタンがあります）。

### 設置時にすること

- スリープ・画面オフ・スクリーンセーバーを無効にする
- 端末を電源に接続する
- 通知やポップアップを切っておく
- 音を出す端末は、映像の右下の`音声を有効にする`を1回タップする。

動画の音声はページを再読み込みすると**オフに戻ります。**

## 画面の見かた

- **左** … 団体ごとの販売状況・混雑状況。まだ送信のない団体は`未報告`と出ます
- 13団体以上が設定されている場合は、10秒ごとにページが切り替わります（右上に`1/3`のようにページ番号）
- **右** … 管理者が選んだ動画。設定がない場合や、管理者が決めた再生開始時刻より前は`映像準備中`と出ます
- **下** … `INFORMATION`の帯。速報・タイムテーブルの案内・固定案内が流れます

表示内容は約1分ごとに自動更新されます。

## 困ったとき

| 画面の表示                            | 状況と対応                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------------ |
| SIGNAGE INITIALIZING / 接続しています | 読み込み中。数秒待っても変わらなければネットワークを確認                             |
| 閲覧URLが無効です                     | URLが再発行されたか、ログイン情報が消えました。管理者に新しいURLを依頼してください。 |
| 通信を確認しています                  | 一時的に接続できていません。表示は最後の状態のまま。回復すると自動で消えます。       |
| 映像準備中 / VIDEO STANDBY            | 動画が未設定か、再生開始時刻より前か、再生できません。管理者に確認してください。     |
